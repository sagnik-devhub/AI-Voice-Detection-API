# AI Voice Detection API

An AI-powered API for detecting and analyzing voice/audio samples.

## 🚀 Features

- AI-generated voice detection
- Audio processing
- Machine Learning based voice analysis
- Transformer-based detection
- CNN-based detection
- REST API using FastAPI
- Interactive API documentation with Swagger

## 🛠️ Technologies Used

- Python
- FastAPI
- PyTorch
- Transformers
- Machine Learning
- CNN
- Hugging Face
- Librosa
